# 자기소개서 반복 탈락 방지 개선 결과

작성일: 2026-08-11

## 결론

프로젝트가 내부 점수와 상대적 후보 1등을 실제 제출 준비로 오인하던 경로를 차단했다. 합격을 보장하는 기능이 아니라, 과거 전형 결과를 다음 작성에 연결하고 미해결 위험이 있는 자기소개서를 `passed/ready`로 표시하지 않는 검증 강화다.

## 확인된 원인

- 기존 rigorous 선발은 모든 후보의 절대 점수가 낮거나 의미 검토가 남아도 상대적 1등을 `passed`로 기록할 수 있었다.
- 전체 감사점수 90 이상이면 문항별 저점과 권장 분량 미달이 다른 섹션 점수로 상쇄될 수 있었다.
- `human_review_recommended=true`인 감사도 CLI와 포트폴리오에서 성공처럼 보일 수 있었다.
- 사용 문서의 탈락 피드백 절차가 실제 원장·CLI·문항전략·후보 검증에 연결되지 않았다.

## 구현

1. `.career_profile/application_outcomes.json` 결과 원장과 `outcome record/validate/summary` CLI를 추가했다.
2. 원장에는 지원서 원문·개인정보를 허용하지 않고, 기관·직무·결과·출처·강약점 코드만 저장한다.
3. V2 `prepare`가 `05_전형결과피드백.json`을 만들고 `05_문항전략.json`에 결과 요구를 주입한다.
4. 공식·확정된 동일기관 약점은 hard 요구, 단일 교차기관 신호와 추정 원인은 review 요구로 제한한다.
5. hard 결과 요구 중 직무능력·지원동기·조직문화·제출표식·성과소유권·면접방어 항목을 결정적으로 검증한다.
6. rigorous 선발에 내부 절대 하한을 추가했다. 심사 중앙값 85, 최저점 70, 핵심 점수 중앙값 28, 미해결 의미 검토 없음이 모두 필요하다.
7. 포트폴리오 ready는 rigorous 절대 하한, 문항별 최소 85·평균 90, 권장 분량 PASS, 사람 검토 없음, 유효한 확정 경험 원장을 요구한다.
8. `audit`는 총점이 높더라도 품질 게이트 실패나 사람 검토가 남으면 종료코드 2를 반환한다.

내부 하한은 프로젝트 품질 검증값이며 채용기관 점수나 합격 확률이 아니다.

## 실행 결과

- 변경 전 기준선: `700 passed, 5 skipped`
- 변경 후 전체 회귀: `710 passed, 5 skipped`
- 추가 적대적 테스트: 전원 0점·`REVIEW_REQUIRED`, 낮은 문항점수, 권장 분량 검토, 잘못된 결과 원장, 원문 필드 삽입, 과거 hard 요구 미충족
- HF 공식 피드백 메타데이터 1건을 로컬 원장에 등록하고 검증했다.
- 같은 기관에는 직무능력·지원사유·조직문화 약점이 hard 요구로 적용된다.
- 다른 기관에는 한 사례를 확정 원인으로 일반화하지 않고 review 요구로만 적용된다.
- 현재 포트폴리오 49건을 읽기 전용 재평가한 결과 `ready=0`이다. 49건 모두 현재 공고·자격·최종 실행 근거가 부족해 `not_ready`로 보수적으로 분류됐다.

## 사용

```powershell
python -m career_pipeline outcome validate --root .
python -m career_pipeline outcome summary --root . --target "지원 기관 직무"

python -m career_pipeline prepare `
  --root . `
  --target "지원 기관 직무" `
  --draft "자기소개서.docx" `
  --posting "공식 채용공고.pdf" `
  --official-source `
  --profile ".career_profile/experience_ledger.json"

python -m career_pipeline finalize `
  --run "career_runs/<run-dir>" `
  --quality-profile max_quality

python -m career_pipeline audit --run "career_runs/<run-dir>"
python -m career_pipeline portfolio build --root . --output-dir ".career_profile/portfolio"
```

## 남은 한계

- 합격 여부는 경쟁률, 가점, 자격, 기관별 평가 기준 등 프로젝트 밖 요인의 영향을 받으므로 보장할 수 없다.
- 현재 49건은 과거 파일 목록 중심이며 활성 공식 공고·자격 판정·새 rigorous 실행이 대부분 없다. 실제 다음 지원은 새 공고로 V2를 다시 실행해야 한다.
- 단일 타기관 탈락 신호는 자동 hard 규칙으로 승격하지 않는다. 반복 증거나 사용자 확인이 필요하다.
- 실제 원서 입력·제출은 수행하지 않았으며 별도 명시 승인 없이는 수행하지 않는다.
