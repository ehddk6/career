# NRS 생산 기본 작성기 전환

사용자 승인에 따라 2026-08-29부터 자기소개서 산문 생성의 기본 전략은 `nrs_v2`입니다.

- 기본 경로는 검증된 논증 경로에서 서로 다른 서사 순서의 후보를 최대 3개 생성하고, 유효 후보만 순서 교차형 심사로 선택합니다.
- 산문 생성에는 허용 사실, 행위자·결과 구분, 문항, 직무 연결, 분량만 전달합니다. 검증 제약과 전략 선행정보는 생성 프롬프트에 전달하지 않습니다.
- 사실·행위자 검증과 자기소개서 장르 게이트는 후보마다 유지됩니다.
- 유효한 NRS 후보가 없거나 후보 선택이 실패하면 기존 `deep_route` 작성기를 대체 경로로 사용합니다. 대체 문안도 같은 장르 게이트를 통과하지 못하면 산출하지 않습니다.
- 생성 보고서 `05_통합논증검색_검증.json`과 `05_NRS_서사선택.json`에서 후보 선택 및 대체 여부를 확인할 수 있습니다.

필요한 경우에만 `--writer-strategy deep_route`로 기존 경로를 명시적으로 선택할 수 있습니다.
