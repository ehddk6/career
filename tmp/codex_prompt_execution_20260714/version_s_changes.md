# Version S 변경 기록

## 편집 원칙

- P2를 기본안으로 유지하고, 세 심사 중 두 명 이상이 겹쳐 지적한 약점만 최소 수정했다.
- 미확인 수치와 새 경험을 추가하지 않았으며, 기한연장과 상시관리의 확인 대상 구분, 원자료 대조, 예외 보고, 처리 이력 기록을 보존했다.
- M7의 문장을 가져오지 않았다.

## 문항별 변경

- 문항 1: ‘자료 한 줄이 기회를 좌우한다’는 과한 일반화와 ‘공공서비스의 신뢰’, ‘판단의 토대’ 같은 상투적 결말을 걷어냈다. 경험·기관 역할·지원 이유·배움·기여의 흐름과 사실 범위는 유지했다.
- 문항 2: 심사자 두 명 이상이 공통으로 지적한 실제 약점이 없어 P2 원문을 유지했다. 절충안의 구체적 결과를 보태면 확인되지 않은 새 사실이 될 수 있어 추가하지 않았다.
- 문항 3: 문항 1과 반복되던 국민연금공단 경험 설명을 줄이고, 분류·표준화 경험에서 원자료 재대조로 이어지는 부분만 남겼다. 기한연장과 상시관리의 서로 다른 점검 항목, 추정 금지, 예외 보고, 후속 조치 기록은 유지했다.
- 문항 4: 후반의 반복 표현을 일부 바꾸고, 앞 내용을 추상적으로 되풀이하던 마지막 대비 문장을 삭제했다. 기업별 환율 영향 구분, 공식 조치, 선별 지원, 보증료 지원, 기한연장 검토, 상시관리와 유의점은 유지했다.

## 글자 수

- 문항 1: 507자
- 문항 2: 549자
- 문항 3: 517자
- 문항 4: 1,150자

글자 수는 각 문항의 제목과 문단 구분 줄바꿈을 제외하고 본문만 이어 붙여 계산했다.
