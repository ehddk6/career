# 새 KakaoTalk 프롬프트 비교 보고서

## 결론

새로 제공한 두 파일은 기존 프롬프트를 대체하는 완성형 실행 계약이라기보다, 기존 Career Pipeline에 흡수할 수 있는 보강 프롬프트다.

- 회사조사 프롬프트는 사업모델·고객·시장·경쟁사·대체재·최근 성과·전략·위험·직무 연결을 폭넓게 다룬다.
- 자기소개서 프롬프트는 실제 행동, 개인 기여 범위, 수치 안전성, 문장 자연스러움과 반복 억제에 강하다.
- 그러나 두 파일 모두 `data_package_id`, 원자료 SHA-256 manifest, claim ID/status, JSON 출력 계약, HARD_FAIL, 블라인드 후보·심사, D3/D4, X/Y 검증을 정의하지 않는다.

따라서 최선의 조합은 다음이다.

1. 기존 Career Pipeline의 원자료 동결·계약 검증·rigorous selection을 유지한다.
2. 새 회사조사 프롬프트를 `04_기업직무조사.json`을 채우는 조사 내용 rubric으로 사용한다.
3. 새 자기소개서 프롬프트를 rigorous 선택 후 자연스러운 한국어와 기여 범위를 다듬는 후처리 rubric으로 사용한다.
4. 후처리 뒤 `validate_draft`, `validate_research_evidence`, 계약 검증, 최종 감사와 X/Y 비교를 다시 실행한다.

## Career Pipeline v22에 적용할 효과

현재 v22는 최종 감사 93/100 `pass`지만 다음 보완점이 남아 있다.

- Q2: 직무 연결성 보완 필요
- Q3: 기관·사업 고유성 보완 필요
- 일부 문항의 문체 위험과 반복성

새 자기소개서 프롬프트의 “경험의 실제 행동 → 판단 기준 → 직무에서 재현할 행동” 흐름은 이 세 항목을 개선하는 데 직접 유용하다. 다만 외부 후보처럼 안전성 검증을 우회하면 Q3 `contribution_overstatement`가 다시 발생할 수 있다.

새 회사조사 프롬프트는 현재 `04_기업직무조사.md`보다 다음 내용을 확장하는 데 유용하다.

- 회사 한 문장 정의
- 고객이 경쟁사·대체재 대신 선택하는 이유
- 최근 성과의 원인과 일회성 여부
- 전략별 성공 조건·비용·위험·직무 역할
- 회사 예상 질문과 역질문
- 조사 중단 기준과 핵심 근거표

## 중요한 한계

이번 두 KakaoTalk 파일은 프롬프트 원문만 제공됐고, 이 프롬프트로 생성된 후보 자기소개서·회사조사·면접팩은 제공되지 않았다. 따라서 이번 결과는 “프롬프트 설계 비교”이며, 새 프롬프트의 실제 산출물 품질 점수는 아니다.

앞서 기록된 외부 후보의 블라인드 중앙값 98점은 새 KakaoTalk 자기소개서 프롬프트의 실행 결과로 귀속할 수 없다. 그 후보는 별도 `data_package_id`로 생성된 기존 산출물이며, Q3 기여 과장과 Q4 근거 연결 문제가 있었다.

상세 feature matrix와 파일 SHA-256은 같은 디렉터리의 `new_prompt_comparison.json`에 기록했다.
