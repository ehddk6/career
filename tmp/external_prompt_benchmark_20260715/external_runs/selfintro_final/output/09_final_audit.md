## DOCX 검증

### 구조 검증: PASS

- ZIP CRC 오류 없음
- 필수 OOXML 파트 존재
- XML/relationship 파트 파싱 성공
- 최종 JSON의 네 답변이 DOCX에 모두 존재
- A4 210×297mm, 여백 상 17 / 우 19 / 하 16 / 좌 19mm
- 2행×4열 글자 수 표 1개, 이미지 0개, 미치환 문자열 0개
- `narrative_proposal`을 기준으로 한국어 자기소개서용 A4·맑은 고딕·간결한 제출본 형식을 named override로 적용

### 시각 렌더 검증: 미완료

- 번들 `render_docx.py`는 필요한 런타임 의존성을 연결한 뒤에도 sandbox 임시 디렉터리 권한 문제로 렌더하지 못했다.
- 설치된 LibreOffice는 변환 프로세스가 충돌했고, Word COM은 응답하지 않았다.
- 따라서 PNG 100% 확대 검수는 완료했다고 주장하지 않는다. Word에서 최종 페이지 나눔과 표·바닥글 위치를 한 번 확인해야 한다.
