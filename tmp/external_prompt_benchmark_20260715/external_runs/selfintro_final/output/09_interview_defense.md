# 최종 면접 방어표

| 문항 | 예상 꼬리질문 | 답변 경계 | 준비할 핵심 |
|---|---|---|---|
| Q1 | 3,000페이지를 어떤 방식으로 2일 만에 정리했나? | 확정 원장은 체계적 분류·2일·지급 절차 기여만 확인한다. | 실제 분류 기준, 본인 담당 범위, 검수 방식은 사용자 본인이 사실대로 보완 |
| Q1 | 신용보증기금과 일반 금융기관의 차이를 어떻게 이해하나? | 본문은 기업 채무 보증, 성장유망기업 지원, 신용조사·보증심사까지만 공식 사실로 사용한다. | 보증이 기업의 금융 접근을 지원한다는 본인 이해를 과장 없이 설명 |
| Q2 | 정렬 방식을 어떻게 바꾸었고 민원 30%는 어떻게 측정했나? | 확정 원장은 키워드·인기순 개선과 민원 30% 감소만 확인한다. | 측정 기간·모수·개인 역할은 확인 가능한 범위로 준비 |
| Q3 | 인턴이 어디까지 판단할 수 있다고 보는가? | 독자 판단·심사·승인을 주장하지 않는다. | 확인한 사실과 미확인 사항을 구분해 담당자에게 보고하는 보조 역할 강조 |
| Q3 | 두 프로그램 결과가 달랐을 때 무엇을 했나? | 비교 분석 보고서 작성과 팀장 보고만 확정됐다. | 차이 원인·최종 선택·성과를 말하려면 실제 기억과 증빙 확인 |
| Q4 | 고환율이 수출기업에는 유리하지 않은가? | 모든 기업을 피해기업으로 일반화하지 않는다. | 수입 투입 비중, 결제 통화, 회수 시점, 가격 전가 가능성으로 영향 구분 |
| Q4 | 지원이 부실 연장이 되지 않게 하려면? | 제안이지 기관 내부 확정 절차가 아니다. | 일시적 유동성 부족과 구조적 부실 구분, 자금 용도·회수·연체·환노출 사후점검 |
| Q4 | 신용보증기금의 실제 지원 사례는? | 공식 확인 사실은 지역 소재 수출기업 등의 유동성·금융비용 부담 완화를 위한 협약보증 공급이다. | 제도명을 `협약보증`으로 정확히 말하고 비공식 세부 혜택을 덧붙이지 않음 |
