# PRIORITY REVISIONS

## P0 - 면접 전 반드시 확인

1. 포털에서 최종 제출된 자기소개서가 `APP-DE94AED7`과 같은지 확인
2. 지원 영업본부·본부점, 서류합격 여부, 개인 면접 일시·장소 확인
3. 연령·과거 KODIT 인턴·출퇴근·채용제한·가점 증빙 확인

## P1 - 경험 방어 깊이

### EX01 결과 비교 분석 보고서: D2 → D4

아래 다섯 문장을 본인 사실로 복원한다.

1. 왜 비교가 필요했는가
2. 어떤 입력·기준·결과 항목을 맞췄는가
3. 어떤 차이가 났고 원인을 어떻게 확인했는가
4. 보고서에서 무엇을 제안했는가
5. 팀장이 무엇을 결정했고 내 분석이 어떤 도움을 줬는가

### EX02 공무원 제안: D1 → D3

`상황 → 요청받은 제안 → 본인 행동 → 실제 결과 → 배운 점`을 확인한다. 결과를 확인하지 못하면 조직 적응 핵심 사례에서 제외한다.

### EX03 시장 프로젝트: D3 → D4

본인 역할, 인터뷰 질문, 5개 시장 선정 기준, 비교표 항목, 최종 산출물, 실행 여부를 확인한다.

### EX04 3,000페이지: D3 → D4

분류 기준, 우선순위, 중간 검수, 오류 처리, 담당자 확인을 복원한다. `150건`, `무오류`, `1주 단축`은 근거 없으면 사용하지 않는다.

## P2 - 말하기 검증

1. Q001~Q012를 녹음해 실제 60초 분량 측정
2. 한 문장 25~35자 안팎으로 끊기
3. “생각합니다” 반복, 체크리스트 나열, 회사소개 암기문장 축소
4. 답변별 핵심 키워드 5개만 남기고 원고 없이 재답변

## P3 - 모의면접

`STANDARD → FACT_CHECK → PRESSURE` 순서로 3회 실행하고, 매 회차 최대 3개 수정만 반영한다.
