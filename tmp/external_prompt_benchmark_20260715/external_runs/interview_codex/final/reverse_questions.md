# REVERSE QUESTIONS

면접 분위기와 남은 시간에 따라 2~3개만 묻는다. 홈페이지에서 바로 찾을 수 있는 숫자나 복지 질문보다 실제 업무 학습과 피드백을 묻는다.

1. “보증 분야 인턴이 근무 초기에 가장 먼저 익혀야 하는 업무 기준이나 자료 항목은 무엇인지 궁금합니다.”
   - 의도: 빠른 적응과 정확성
2. “기한연장과 기업신용 상시관리 업무를 보조할 때 인턴이 자주 놓치기 쉬운 부분은 무엇입니까?”
   - 의도: 오류 예방과 직무 현실 이해
3. “담당자께서 업무를 안심하고 맡길 수 있었던 인턴에게 공통적으로 보였던 확인·보고 습관이 있다면 듣고 싶습니다.”
   - 의도: 기본인성과 직무능력 동시 연결
4. “인턴이 업무를 배우는 과정에서 피드백은 주로 어떤 방식과 주기로 이루어지는지 궁금합니다.”
   - 의도: 피드백 수용성과 학습 방식
5. “최근 생산적 금융과 위기기업 지원이 강화되는 상황에서 영업점 실무가 특히 중요하게 보는 변화가 있다면 무엇입니까?”
   - 의도: 2026년 기관 방향과 현장 연결. 시간이 충분할 때만 사용

## 피할 질문

- 합격 가능성, 정규직 전환 보장, 쉬운 업무 여부
- 공고에 이미 적힌 근무기간·급여·근무시간
- 내부 심사기준이나 고객기업 비공개정보를 요구하는 질문
