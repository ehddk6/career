## 충돌 처리

- `input/직무기술서/*.pdf`는 모두 한국도로공사서비스 채용 자료다. KODIT 면접 근거로 사용하면 기관·직무 혼동이 발생하므로 제외했다.
- `input/경험정리/경험정리.docx`에는 사실 원문과 작성 예시·보완 제안이 섞여 있다. 확정 경험 원장에 등록되지 않은 파생 수치와 결과는 면접 답변에서 사용하지 않는다.
- 이전 렌더링 PDF와 `draft_final.json`의 문장·글자 수가 다르다. 현재 실행의 기준은 SHA-256이 동결된 `draft_final.json`이다.
