# Checkpoint — 자기소개서 writer v2 holdout 실행 — 2026-08-26 12:22

## The story so far

writer v2의 12문항 회귀시험 R10은 12/12 문항, preflight, 1,370개 파일 manifest 검증을 모두 통과했습니다. 선택된 답안의 사실 오류와 감사식 메타 문구 누출은 각각 0건이었습니다. 현재 원 실험과 겹치지 않는 사전 등록 holdout 9문항 R11을 실행 중이며 4문항이 완료됐습니다. 계획 모델이 빈 근거를 반환하면 승인 사실만으로 구성한 공정한 공통 경로로 전환하는 보완을 적용했습니다.

## Decided

- NRS는 인간 blind 검토와 사용자 승인 전까지 shadow-only로 유지하며, 기본 writer는 자동으로 바꾸지 않습니다.
- 기존 6:6 결과는 보존하되 `genre_contract_failure`로 writer 효능 근거에서 제외합니다.
- 모델 식별자는 확인할 수 없으므로 manifest에 `null`로 기록합니다.
- control과 NRS는 동일한 프롬프트 계약, backend, 후보 수, 재시도 예산 및 장르 게이트를 사용합니다.

## Waiting on the user

- Holdout 결과물의 blind 평가와 production opt-in 승인만 사용자 판단이 필요합니다. 실행과 검증은 계속 진행합니다.

## Next first action

R11 실행 프로세스가 끝날 때까지 감시하고, 9개 checkpoint·preflight·manifest를 검사한 뒤 전체 pytest를 실행합니다.

## Tried

- 이전 R1–R9 실행은 감사 기록으로 보존했습니다. 초기 실행 안정성, 기여도 검증의 오탐, 계획 경로의 근거 누락 문제를 수정했으며 기존 산출물은 삭제하지 않았습니다.
- 선택한 수치와 실제 산문 수치가 일치하지 않아 발생한 오탐은 산문에 보이는 승인 수치만 참조에 연결하도록 수정했습니다.
- 선택하지 않은 선택형 조사 근거가 본문에 보이지 않아도 연결되던 문제는, 실제 문장에 나타난 경우에만 연결하도록 수정했습니다.
