# Checkpoint — 자기소개서·지원서 재발 방지 강화 완료 — 2026-08-30 17:26

## The story so far

서울시설공단 지원서에서 드러난 일반적 지원동기, 보고서식 문체, 핵심 수치 누락, 만료 어학·증빙 누락, 내부 점수와 지원서 완성도 혼동을 코드 수준에서 차단했다. NRS 후보뿐 아니라 수동 fallback과 최종 감사도 동일한 장르·필수수치 계약을 재검사한다. 자격·어학은 이번 지원서에서 선택한 항목과 증빙 파일을 명시적으로 결속하며, 미선택 만료 항목은 제외하고 선택 만료·증빙 누락은 차단한다. 전체 회귀는 915 passed, 7 skipped이고 컴파일·diff 검사가 통과했다.

## Decided

- D-004: 서울시설공단 사무 인턴 공고를 최초 production NRS end-to-end 실행 대상으로 사용했다.
- D-002: NRS v2 기본 작성기를 유지하되 장르·필수수치·최종감사 게이트를 모든 작성 경로에 적용했다.
- 내부 100점은 `career_artifacts_only`이고 지원서 완성도나 합격 확률이 아니라는 범위를 산출물에 기록했다.
- 골든패스 `complete`는 `artifact_pipeline_only`이며 실제 제출 완료와 구분한다.
